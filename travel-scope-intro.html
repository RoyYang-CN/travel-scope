地图路线连线 核心

📋

双视图切换

卡片列表查信息，地图路线看行程，一键Tab切换

🗓️

每日行程编排 核心

每天展示景点、餐厅、住宿和必要的交通节点；路线方案切换时保持完整行程。

📊

Excel多Sheet

输出结构化 Excel、Markdown 和 HTML；字段统一，便于复核、打印和二次编辑。

📝

Markdown全文

图片与来源透明

公开示例使用中性占位图；真实运行时按授权和 API 返回情况补图，不把占位图伪装成实拍图。
