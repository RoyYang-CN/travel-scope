# Indonesia example

Historical snapshot regenerated with Travel-Scope v2.9.1.

This case demonstrates destination discovery and the Bali–East Java route corridors, including the Surabaya–Bromo–Banyuwangi/Ijen–West Bali line and Bali island subcorridors.

Included formats:

- Chinese and English HTML;
- Chinese and English Markdown;
- Chinese and English delivery Excel.

This is not live data. Prices, ratings, schedules, weather, ferry availability, entry rules and hotel availability must be rechecked before travel. Images use a neutral placeholder URL; no provider image URL or API key is included.
