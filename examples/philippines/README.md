# Philippines example

Historical snapshot regenerated with Travel-Scope v2.9.1.

This case demonstrates multi-island itinerary planning, ferry and land-transfer edges, marine activities, and alternative route structures around Cebu, Bohol and Siquijor.

Included formats:

- Chinese and English HTML;
- Chinese and English Markdown;
- Chinese and English delivery Excel.

This is not live data. Prices, ratings, schedules, sea conditions, ferry availability, entry rules and hotel availability must be rechecked before travel. Images use a neutral placeholder URL; no provider image URL or API key is included.
