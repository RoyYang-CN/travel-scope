# Example outputs

These examples were regenerated with Travel-Scope v2.9.1 from historical research snapshots.

- They demonstrate the same structured data model in Chinese and English.
- Prices, opening hours, availability, weather, transport schedules and entry rules are not guaranteed current.
- Images are intentionally replaced with a neutral placeholder URL for redistribution safety.
- Verify all dynamic information before making travel decisions.

## Cases

- [Indonesia](indonesia/README.md): volcano, island and route-corridor planning.
- [Philippines](philippines/README.md): multi-island transport and marine activities.
- [Offline synthetic demo](demo/): no live provider data and no API key required.
