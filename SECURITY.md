# Security

Please do not report exposed API keys or other sensitive data in a public issue.

For security reports, contact the maintainer privately at `hnzzlulu@gmail.com`. Do not include API keys in GitHub Issues, pull requests, screenshots, or public logs. If a key may have been exposed, rotate or revoke it first, then send the incident summary and affected commit/path by email.

This mailbox is a maintainer contact for this project and may receive spam; do not use it for general support.

Never commit provider API keys, raw provider responses, private travel records, or image URLs containing credentials.
