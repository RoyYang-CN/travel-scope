# 互动式前置 QA

加载 Skill 后，在目的地发现和高成本搜索前展示以下配置，并让用户确认：

| 项目 | 默认值 | 说明 |
|---|---|---|
| 运行模式 | 有有效凭证时 Live，否则 Demo | Demo 只读取脱敏 fixture，不调用供应商 API |
| 目的地分支 | 根据目的地识别 | 国内使用高德/百度网页跳转，海外使用 Google Maps/Apple Maps 网页跳转 |
| 地图模式 | 普通网页跳转 + 本地路线示意 | 不加载供应商 JS 和地图瓦片 |
| 实时地图增强 | 关闭 | 用户明确启用后才要求对应地图 Key |
| 路线粒度 | 每天一个主要目的地/大区域 | 不把当天住宿、餐厅、景点串成多点地图路线 |
| 详细交通 | Excel 保留 | 包含汽车站、港口、机场、渡轮等独立交通节点 |
| 研究深度 (Q7) | 用户指定（精简/标准/深度/超级深度） | 精简(40+ POI)/标准(100+ POI)/深度(180+ POI,双源核验)/超级深度(300+ POI)；兼容旧称：经典(标)、全景(超深) |
| 行程节奏 (Q8) | 用户指定（紧凑/适中/宽松） | 紧凑(换宿率≤0.75)/适中(换宿率≤0.60)/宽松(换宿率≤0.45)；兼容“慢速松弛”别名 |
| 范围 | 用户确认 | 国家级请求仍需目的地发现、经典走廊审计和排除说明 |

确认结果必须写入本次运行 manifest，并在后续生成中保持一致。

没有 API Key 不是基础 HTML 和普通网页导航的阻断条件。真正需要暂停的情况包括：用户未确认范围、Live 模式凭证无效、路线走廊审计失败或关键地点缺少可核验证据。
