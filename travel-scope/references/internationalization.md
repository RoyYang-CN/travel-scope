# Travel-Scope 国际化输出规范

## 目标

同一份通过来源审计和全链路 QA 的旅行数据，同时服务中文用户和国际游客。语言转换只改变展示层，不改变目的地池、路线、交通边、POI、评分口径或证据状态。

## 名称展示

| 字段 | 作用 |
|---|---|
| `name_zh` | 中文官方/地图名称，用于问路、打车和现场核对 |
| `name_en` | 常用英文名称；没有可靠英文名称时留空 |
| `name_pinyin` | 中文名称拼音，适合地址检索和口头沟通 |
| `address_zh` | 中文地址 |
| `address_en` | 英文地址或结构化地址翻译 |

英文输出默认使用 `English Name (中文名)`。英文缺失时只显示中文，并在研究版标记 `translation_status=missing`，禁止凭空创造官方译名。

## 中国国际游客信息

信息应进入 `PRACTICAL` 或 `DYNAMIC_INFO`，并记录来源、最后核验日期和动态等级：

- 入境、签证和停留规则；
- 微信支付、支付宝、银行卡和现金；
- 手机网络、eSIM、漫游和常见网络限制；
- 铁路 12306、机场、网约车和城际交通；
- 实名预约、门票、景区开放和身份证件要求；
- 中文地名、打车可复制地址和必要拼音；
- 英语服务、外卡支付、行李寄存和酒店入住注意事项；
- 文化礼仪、摄影限制、安全和出发前复核提醒。

## 来源与翻译边界

- 平台评分、搜索补充、AI 推荐分必须分开呈现；
- 搜索摘要不是平台 API 数据，不得在英文版包装成官方评分；
- 动态政策优先使用官方来源；
- 描述没有可靠英文翻译时保留中文原文，不把机器翻译标记成官方内容；
- HTML、Markdown 和 Excel 必须从同一份结构化数据生成，禁止分别手工修改。
