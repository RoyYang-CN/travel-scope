# Travel-Scope v3.1.0

## v3.1.0 图片来源与跨城市输出闭环

- 生成前拒绝旧构建脚本产生的虚构 Unsplash 图片 ID。
- 海外 Live 模式拒绝非 Google Places 图片映射，避免把旧模板数据当作真实图片交付。
- 新增远程图片可用性门禁：逐张请求图片并要求 HTTP 200 与 `image/*` 内容类型。
- 公共生成器、城市数据构建和独立输出 QA 统一执行图片来源、实际资源唯一性和可访问性检查。
- 保留 v3.0.6 的 POI 图片去重、坐标回写、交通节点和潜水分类自适应规则。

## v3.0.6 图片来源与跨类别复用门禁

- 图片去除缓存参数后按真实资源 ID 比较，避免通过 `sig` 等参数伪装成不同图片。
- 生成前阻断酒店、餐厅、景点、潜水点之间的图片复用，避免错误 HTML/Excel 交付。
- 国际 Live 模式要求每个 POI 有独立的 Google 图片映射；Demo 仍可使用离线样本，但同样经过真实资源去重检查。
- 静态输出 QA 增加去查询参数后的图片复用检查。
- Demo 模式不再跳过图片结构校验；发现跨类别复用时会在生成前阻断。
- 菲律宾本次数据必须先重新生成真实、按 POI 独立归属的 Google 图片映射，才允许交付 HTML/Excel。

## v3.0.5 交通节点与路线边分层

- HTML交通分类仅展示独立可定位的交通节点；路线边的费用、班次、耗时、距离、预约和注意事项保留在 Excel。
- 新增 `TRANSPORT_NODES`，支持同一目的地配置汽车站、港口等多个节点，并让路线地图分别使用节点坐标。
- Excel新增“交通节点”工作表；“交通信息”继续输出详细的点到点交通边字段。
- 交通边可选填“出发节点/到达节点”链接字段，解决同一目的地有多个车站、港口时的精确落点问题。
- 旧版仅有路线边的数据仍可兼容生成，但端点会明确标记为“待补充具体车站/港口”，不冒充已核验的站点。

## v3.0.4 点到点交通字段扩展

- 交通信息支持出发地、目的地、交通方式、预计耗时、距离、参考费用、预约要求、注意事项和来源/核验状态。
- 兼容旧版9字段 TRANSPORT 数据；新增字段为空时不伪造交通事实。
- 详细交通信息落入 Excel，HTML 不增加每日交通展开。

## v3.0.3 分类自适应与图片类别门禁

- 真实潜水与一般水上活动自动分流；无真实潜水时隐藏潜水分类和统计。
- 水上活动在每日行程、HTML、Markdown 和 Excel 中统一按景点/活动处理。
- 明确禁止跨类别随机模板图片作为 Live 正式 POI 图片。

## v3.0.2 Excel-EN 动态数据语言化修复

- 修复 `--language en` 只翻译 Excel 工作表名和表头、数据行仍写入中文的问题。
- 英文 Excel 现在会语言化目的地区域、体验、季节、到达方式、路线、交通、类别、说明和行程字段。
- 保留中文名称列作为外国游客问路和收藏时的中文原名；英文名称列继续优先使用结构化英文名称。
- 增加英文 Excel 回归门禁：非中文名称字段出现未翻译 CJK 文本时阻断生成。

## v3.0.1 POI 身份、坐标与输出闭环修复

- Google Maps 导航改为 Place ID/POI 名称优先，坐标仅作备用，避免错误源坐标把导航带到海里。
- 国际 Excel 增加 Google 图片1、Google 图片2 和 Google Place ID，并与 HTML 使用同一 POI 数据对象。
- 国际 Live 缺少已验证 Google Place ID 或 Google 图片时阻断正式生成。
- 国内保持高德主接口、百度验证/补图/导航；Live 国内 POI 缺少高德 POI ID 或发生跨 POI 图片复用时阻断。
- Demo 模式仍不调用供应商 API；旧攻略与运行输出不进入开源源包。

## 本版本基线

- 国内版本：高德主数据源；百度重点核验、补图和导航；搜索引擎作为独立补充来源。
- 国内卡片：缺失评价数不显示“待核验”；无有效点位级搜索证据时隐藏搜索补充标签。
- 国内路线：正式路线编排器按质量、空间距离、去重和住宿衔接选择每天 2-3 个景点、1 个餐厅和 1 个住宿，开放时间、用餐时段和驾驶时长仅作参考提示。
- 所有点位独立生成 AI 推荐分，并与平台评分隔离。
- 超级深度搜索使用持久化缓存、批次结果和断点恢复。
- 国内 POI 增加设施类过滤、嵌套景区语义去重和行政区/坐标一致性校验，拒绝明显异地同名点位。
- 国内卡片和路线弹窗同时提供高德、百度静态跳转；百度跳转只在本地生成 URL，不调用百度地点检索 API。
- 国际化输出：同一份已验证数据可生成中文、英文或双语交付物；英文版本保留中文名称，便于问路、打车和现场核对。
- 输出格式统一支持 HTML、Markdown 和 Excel；英文文件使用 `-en` 后缀，不改变中文文件命名。
- 英文输出只翻译稳定的界面、表头和结构化字段，不把未经人工/来源支持的中文描述伪装成专业英文内容。
- 中国国际游客模式的签证、支付、网络、预约、交通和中文点名信息进入 `PRACTICAL`/动态信息数据，不另建一套路线逻辑。
- 新增 `demo/live` 运行模式；Demo 模式读取脱敏 `fixtures/demo.json`，不需要 API Key，也不访问供应商接口，并在输出中显式标注离线演示数据。

国际版本逻辑保持不变。
